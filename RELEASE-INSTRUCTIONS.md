# Distribution Files for GitHub Release

The distribution packages are too large for git (>100 MB) and should be uploaded to GitHub Releases instead.

## Files to Upload to Release v1.1.0:

1. **MyJournal-1.1.0-x86_64.AppImage** (102 MB)
   - Main distribution for all Linux distros
   - Recommend using with Gear Lever

2. **MyJournal-1.1.0-linux.tar.gz** (101 MB)
   - Alternative installation method
   - Includes install.sh script

## How to Create a GitHub Release:

1. Go to: https://github.com/corey2120/MyJournalDesktop/releases/new
2. Tag version: `v1.1.0`
3. Release title: `My Journal Desktop v1.1.0 - PDF Export & Email`
4. Description: Copy from CHANGELOG-v1.1.0.md
5. Upload the two files above
6. Check "Create a discussion for this release"
7. Publish release

## Download URLs (after release):

Once published, users can download from:
- https://github.com/corey2120/MyJournalDesktop/releases/latest

Update README.md installation section with direct download links after release.
